## 🐍 Bem-vindo ao laboratório Python

Este repositório é uma trilha prática de **lógica de programação com Python**. São **50 exercícios resolvidos**, organizados para você começar pelo essencial, ganhar confiança e chegar às funções aplicadas a problemas de física.

> Não é sobre decorar comandos. É sobre treinar o raciocínio até conseguir enxergar soluções.

<div align="center">

| 🧪 Exercícios | 🧭 Módulos | 🎯 Nível | ⚙️ Ambiente |
|:--:|:--:|:--:|:--:|
| **50 resolvidos** | **4 etapas** | **Iniciante → Intermediário** | **Python 3** |

</div>

## ▶️ Como executar os exercícios

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone este repositório.
3. Abra um terminal dentro da pasta do exercício.
4. Rode:

<pre><code>python ex1.py</code></pre>

Troque <code>ex1.py</code> pelo arquivo que quer testar. Alguns exercícios pedem informações no terminal — responda e veja a lógica funcionando.
